This is firmware for BILBO Tuner. BILBO Tuner uses a piezoelectric sensor to get a more accurate main frequency component of the sound.

The firmware runs on a SAMD21G18A microcontroller and uses hardware interrrupts for signal edge detection to conserve computing power. Timers make it possible to convert the signal to an actual frequencies.
